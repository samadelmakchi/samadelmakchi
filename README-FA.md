## 👨‍💻 درباره من

من یک **توسعه‌دهنده فول‌استک**، **برنامه‌نویس بازارهای مالی** و **معمار نرم‌افزار** با بیش از **۲۵ سال** تجربه عملی در طراحی، توسعه و تحویل سیستم‌های مقیاس‌پذیر و پایدار هستم. تخصص من پنج حوزه اصلی را پوشش می‌دهد:

| حوزه | فناوری‌ها |
|------|-----------|
| 🐍 **بک‌اند و معماری** | FastAPI, Flask, SQLAlchemy, Microservices, DDD, Event-Driven, Resilience Patterns |
| 🎨 **فرانت‌اند** | React, Next.js, JavaScript, Tailwind CSS, Bootstrap |
| 📈 **بازارهای مالی** | MQL5, MQL4, Pine Script, backtrader, vectorbt, MetaTrader5 API, TA-Lib |
| 🧠 **یادگیری ماشین و هوش مصنوعی** | PyTorch, TensorFlow, Scikit-learn, XGBoost, LangChain, ChromaDB |

معتقدم به نوشتن کد تمیز، مستند و تست‌پذیر با رعایت **PEP8**، **Type Hints**، **SOLID Principles** و **Design Patterns**.

## 🚀 ۸ پروژه برتر

### ۱. 🏢 پلتفرم میکروسرویس سازمانی (ERP/CRM) — طراحی و توسعه بک‌اند

**مشکل حل‌شده:** طراحی و پیاده‌سازی معماری میکروسرویس برای سازمانی با بیش از ۵۰ سرویس، در حوزه‌های ERP، CRM و LMS.

**فناوری‌های کلیدی:**
- FastAPI, SQLAlchemy, Alembic
- PostgreSQL, Redis, RabbitMQ, Celery
- Domain-Driven Design, Event-Driven Architecture
- Pytest, Locust, Docker, GitHub Actions

**نکات فنی برجسته:**
- معماری میکروسرویس با **Domain-Driven Design** برای بیش از ۵۰ API **RESTful** مستندشده
- ارتباط **Event-Driven** با RabbitMQ، الگوهای **Circuit Breaker** و **Retry**
- مدل‌سازی داده و بهینه‌سازی کوئری با PostgreSQL + SQLAlchemy/Alembic؛ کش با Redis
- تست خودکار با Pytest و تست بار با Locust؛ استقرار کانتینری با Docker و CI/CD با GitHub Actions

---

### ۲. 📈 پیش‌بینی شاخص‌های اقتصاد کلان — سرویس بک‌اند و API پیش‌بینی

**مشکل حل‌شده:** ترکیب مدل‌های اقتصادسنجی کلاسیک با یادگیری عمیق برای پیش‌بینی قیمت طلا، دلار و نفت با دقت بالاتر از مدل‌های سنتی، به‌صورت API تولیدی.

**فناوری‌های کلیدی:**
- FastAPI, Pydantic
- Statsmodels (VAR, ARIMA), Prophet
- PyTorch (LSTM)
- Pandas, Celery, Redis, Docker

**نکات فنی برجسته:**
- ترکیب VAR/ARIMA با LSTM و ارائه آن به‌صورت **API پیش‌بینی** با FastAPI
- معماری **Event-Driven** برای دریافت داده روزانه و بازآموزی منظم مدل‌ها با Celery + Redis
- پایپ‌لاین داده با Pandas و اعتبارسنجی دقیق ورودی/خروجی با Pydantic

---

### ۳. 🤖 صندوق ورودی یکپارچه ۶ پیام‌رسان با LLM و RAG — بک‌اند و ارکستراسیون سرویس

**مشکل حل‌شده:** دریافت و پاسخ خودکار پیام‌ها از ۶ پلتفرم (واتساپ، تلگرام، اینستاگرام، روبیکا، بله، ایتا) با هوش مصنوعی مولد (RAG) و تاریخچه مکالمه. کاهش زمان پاسخ از **۱۰ دقیقه به ۱۰ ثانیه**.

**فناوری‌های کلیدی:**
- FastAPI, Pydantic
- LangChain, ChromaDB
- Telethon
- PostgreSQL, Redis, Celery, Docker

**نکات فنی برجسته:**
- سرویس بک‌اند برای ارکستراسیون پیام‌های ورودی/خروجی ۶ پیام‌رسان با **Adapter Pattern**
- پایپ‌لاین **RAG** با LangChain + ChromaDB روی معماری **Event-Driven** و صف Celery/Redis
- مدیریت وضعیت مکالمه در PostgreSQL؛ اعتبارسنجی دقیق با Pydantic

### ۴. 🐳 استقرار خودکار با Docker + GitHub Actions — بک‌اند تحویل پیوسته

**مشکل حل‌شده:** با هر `git push` روی شاخه main، پروژه پایتون به‌صورت خودکار تست، بیلد و روی VPS با Docker مستقر می‌شود. کاهش زمان استقرار از **۳۰ دقیقه به ۲ دقیقه**.

**فناوری‌های کلیدی:**
- Python, Ansible, GitHub Actions
- Docker, Docker Compose, Portainer
- Nginx, Gunicorn, PostgreSQL

**نکات فنی برجسته:**
- سرویس/اسکریپت‌های بک‌اند برای اتوماسیون استقرار با Ansible و GitHub Actions روی سرورهای لینوکس
- **Blue-Green Deployment** برای کاهش downtime به نزدیک صفر با health-check خودکار
- Dockerfile چندمرحله‌ای برای **کاهش ۷۰٪ حجم image**؛ مدیریت امن توکن با GitHub Secrets
